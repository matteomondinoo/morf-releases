# Morf per Windows

Morf converte i file con una ruota: selezioni i file in Esplora file, premi **Ctrl+Maiusc+Spazio** e scegli il formato.

## Scarica

**[Scarica l'ultima versione](https://github.com/matteomondinoo/morf-releases/releases/latest)** → apri «Assets» e scarica `Morf_…_x64-setup.exe`.

Requisiti: Windows 10 o 11 (64 bit). Non servono permessi da amministratore.

## Installazione

1. Apri il file scaricato.
2. Se compare **«Windows ha protetto il PC»**: clicca **Ulteriori informazioni** → **Esegui comunque**. Succede perché Morf non è firmato da un editore registrato.
3. Fatto: l'icona di Morf compare vicino all'orologio (se non la vedi, clicca la freccina ^ accanto all'orologio).

## Uso

- Seleziona uno o più file in Esplora file o sulla scrivania e premi **Ctrl+Maiusc+Spazio**.
- Nella ruota: **1–9** sceglie, **Tab** passa a Strumenti, **Esc** chiude.
- La scorciatoia si cambia da Impostazioni (clic sull'icona → ingranaggio).

## Aggiornamenti

Morf controlla da solo se c'è una versione nuova: quando c'è, clicca l'icona e poi **Installa e riavvia**.

## Qualcosa non va?

Clicca l'icona di Morf → **Copia diagnostica** e incolla il testo nel messaggio a Matteo. Non contiene nomi di file né cartelle.
